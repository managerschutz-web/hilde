# Hilde.Media – Phase 3

Datei-Import (WAV, MP3, M4A, FLAC, OGG, AAC, MP4, MOV, MKV, AVI, WEBM) über ein mitgeliefertes
`ffmpeg.exe` (LGPL-Build), Normalisierung auf 16 kHz Mono PCM, Auftragswarteschlange auf Basis der
Tabelle `jobs` in `hilde.db` (übersteht Neustarts). Originaldateien werden nie verändert.
