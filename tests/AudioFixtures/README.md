# Audio-Testsatz (deutsch)

Für die Abnahme wird hier ein dokumentierter Testsatz abgelegt: je Datei `NAME.wav` (16 kHz Mono) und
`NAME.txt` (Referenztext). Inhalte gemäß Pflichtenheft Kap. 10: Fachbegriffe (eVB, HSN/TSN,
Gewerbe-Rechtsschutz), Eigennamen (MARTENS & PRAHL), Beträge, Termine, Selbstkorrekturen
(„am Dienstag, nein, am Mittwoch“), Füllwörter, Englisch-Anteile. Aufnahmen nur mit Einwilligung der
Sprechenden; keine echten Kundendaten.

Die Wortfehlerrate (WER) wird nach dem ersten Hardware-Benchmark als Grenzwert festgelegt.
